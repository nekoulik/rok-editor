# ⚔️ RoK Editor — Редактор описаний для Rise of Kingdoms

Профессиональный веб-редактор для создания стильных описаний альянсов в игре Rise of Kingdoms.

##  Быстрый старт

1. Скачай или склонируй проект
2. Открой `index.html` в браузере (двойной клик)
3. Готово! Никаких зависимостей не нужно.
