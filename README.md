# ⚔️ RoK Editor — Редактор описаний для Rise of Kingdoms

[![GitHub](https://img.shields.io/badge/GitHub-RoK_Editor-blue?logo=github)](https://github.com/nekoulik/rok-editor)
[![License](https://img.shields.io/badge/License-MIT-green)](LICENSE)
[![Version](https://img.shields.io/badge/Version-2.1.0-gold)](https://github.com/nekoulik/rok-editor)

**RoK Editor** — бесплатный веб-редактор для создания стильных описаний альянсов в игре **Rise of Kingdoms**. Помогает лидерам и офицерам альянсов быстро оформлять информацию о наборе, правилах и контактах с использованием цветного текста и сотен символов.

🌐 **Демо:** [nekoulik.github.io/rok-editor](https://nekoulik.github.io/rok-editor)

---

##  Возможности

### 🎨 Оформление текста
- **Разноцветное название** альянса из нескольких частей с разными цветами
- **Настраиваемые размеры шрифта** для заголовка, ролей и футера (10–100 px)
- **Иконки по бокам** названия (опционально)
- **Автоматические пробелы** после символов для корректной работы в RoK

###  Панель символов
- **728 символов** в **16 категориях**:
  - ⚔️ Оружие и война
  - ✦ Звёзды и искры
  - ➤ Стрелки
  - ◆ Геометрия
  - ─ Линии и рамки
  - ♪ Музыка
  - ♔ Шахматы
  - ♠ Карты
  - ☀ Астрономия
  - ❤ Сердца
  - 👍 Руки и жесты
  - 🌸 Природа
  - © Другие
  - 1️⃣ Цифры и числа
  - 🅰 Буквы и текст
  - 😀 Смайлы и эмоции

### ️ Предпросмотр и экспорт
- **Живой предпросмотр** — сразу видно результат
- **Копирование в 1 клик** — готовый код в буфер обмена
- **Формат RoK** — совместимость с тегами `<size>`, `<color>`, `<b>`, `<i>`

### 🛠️ Интерфейс
- **Модальные окна**: Возможности, О проекте, ВКонтакте, Обратная связь, Поддержать
- **Адаптивный дизайн** — работает на десктопе и мобильных
- **Фоновое изображение** в стиле RoK
- **Без рекламы и регистрации** — данные не отправляются на сервер

🎮 Как использовать
1,Шаг 1: Название альянса
2.Нажми "+ Добавить часть названия"
3.Введи текст (например, Black)
4.Выбери цвет (например, голубой #00aaff)
5.Добавь ещё часть (например, PieCe красным #ff1900)
6.При желании добавь иконки по бокам

Шаг 2: Роли и строки
1.Настрой цвет ролей и значений
2.Нажми "+ Добавить строку"
3.Заполни: иконка, название роли, значение
4.Повтори для всех ролей (Семья, Советник, Посланник и т.д.)

Шаг 3: Финальная строка
1.Введи текст (например, "По всем вопросам писать посланнику")
2.Настрой цвет и размер

Шаг 4: Генерация и копирование
1.Нажми "✨ Сгенерировать код"
2.Проверь результат в блоке "👁️ Предпросмотр"
3.Нажми " Копировать код"
4.Вставь в описание альянса в RoK
